Unlock the main screen in one call: wake the device, dismiss the keyguard, and enter the lock screen credential once. The credential is used only for this call, never stored, never logged, and never echoed back in the result; the result only says whether the device is unlocked. If the device is already unlocked, return unlocked without entering anything. Use it only when the caller explicitly asks to unlock, with a credential they supplied for this call. Do not invent a credential, do not retry a failed credential, and do not use it for payments or confirmations.
