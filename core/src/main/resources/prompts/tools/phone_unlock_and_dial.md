Unlock the main screen and open the dialer with the given number prefilled, in one call. The credential rules are the same as phone_unlock: used once for this call only, never stored, never logged, never echoed back. The dial rules are the same as phone_dial: the call itself still needs one tap on the dialer afterwards. Use it only when the caller explicitly asks to unlock and dial a named number, with a credential they supplied for this call. Do not invent a credential or a number, and do not retry a failed credential.
